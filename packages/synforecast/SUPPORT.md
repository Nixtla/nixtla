# Support

## Usage questions

Ask usage and integration questions in the
[Nixtla community Slack](https://join.slack.com/t/nixtlacommunity/shared_invite/zt-1pmhan9j5-F54XR20edHk0UtYAPcW4KQ).
Include the SynForecast version, Python version, dataframe engine, operating
system, and a minimal example when possible.

## Bugs and feature requests

Use [GitHub Issues](https://github.com/Nixtla/synforecast/issues) for
reproducible bugs, documentation problems, and feature requests. The issue
templates describe the information needed for each report.

SynForecast is an alpha open-source project. Maintainers prioritize security
issues, regressions, and broadly useful fixes, but do not guarantee a response
time or implementation timeline.

## Security

Do not report vulnerabilities in a public issue. Follow the private reporting
instructions in [SECURITY.md](SECURITY.md).
