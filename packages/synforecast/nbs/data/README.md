# Documentation data

`air_passengers.csv` contains the classic Box–Jenkins monthly international
airline passenger totals from 1949 through 1960, in thousands. It is the
`AirPassengers` dataset distributed with R's `datasets` package.

Source: [R documentation for `AirPassengers`](https://search.r-project.org/R/refmans/datasets/html/AirPassengers.html).
